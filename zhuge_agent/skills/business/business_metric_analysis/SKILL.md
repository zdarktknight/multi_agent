# 企业指标语义分析

用于处理业务人员的经营指标问题，例如“本月华东区域销售额、环比多少，按城市排序”。

## 适用问题

- 本月华东区域销售额、环比多少，按城市排序。
- 近 7 天各城市 GMV 和同比是多少？
- 本季度直营渠道收入按省份排序，并给出柱状图。

## 执行原则

1. LLM 可以参与自然语言语义识别和最终文字组织。
2. 指标口径必须来自企业指标语义库，不能让 LLM 临时编造。
3. 查询计划必须是结构化 JSON Plan，并接受权限、数据域、字段和口径校验。
4. 数仓计算必须由确定性工具执行，LLM 不直接计算指标值。
5. 可视化输出必须基于查询结果生成，包括表格和图表配置。
6. 原因洞察只能基于当前结构化结果做可解释总结，不引入外部事实。
