# DCS 位号查数

用于处理“现在/当前/最近某装置的某个指标是多少”这类问题。

## 适用问题

- 现在 2# 反应釜温度是多少？
- 当前 2# 反应釜压力和温度分别是多少？
- 查询 R-201 的温度、压力、冷却水流量。

## 执行原则

1. 只做数据读取和结构化表达，不做趋势预测、归因诊断或操作建议。
2. 数值必须来自 DCS / 时序库工具输出，不能由 LLM 推测。
3. 回答必须包含数值、单位、数据时间和数据来源。
4. 如果点位不存在或数据质量不足，应明确说明缺失项。
