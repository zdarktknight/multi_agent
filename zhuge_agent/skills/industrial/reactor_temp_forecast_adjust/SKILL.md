# 反应釜温度偏高归因与调整建议

用于处理“温度为什么偏高、是否会超限、应该怎么调”这类问题。

## 执行原则

1. Router 和 Planner 可以使用 LLM 做语义理解和执行计划组织。
2. DCS 取数、小模型预测、SOP 阈值判定、知识库检索必须是 `no_llm`。
3. Composer 只能把上游结构化结果组织为文案，不得生成新的数值。
4. Post-check 必须核对回答中的关键数字是否来自工具输出。
5. 输出动作只作为建议，涉及 DCS 参数、报警阈值或现场操作必须人工确认。
